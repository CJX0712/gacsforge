# Model Card — GACSForge GACS

## 用途
- 半监督分类：少量标注（每类 8 个）+ 大量无标注样本场景下的分类。
- 输入：特征矩阵（低维连续特征最佳，digits 64 维亦可）；输出：类别预测与概率。
- 典型场景：标注预算受限的工业检测、医学初筛、文本冷启动分类。

## 数据
- 训练协议假设：labeled/unlabeled 同分布（i.i.d. 或流形连续）。
- 实测数据：6 组（4 合成 2D 结构数据 + sklearn digits 真实数据子采样）。

## 指标（3 seeds mean±std，真实运行输出）
- aggregate macro-F1：GACS 0.7711±0.0307 vs 最强基线 supervised_rf 0.7176±0.0352（Δ=+0.0536，显著）
- 结构性数据（xor_gauss/spiral）增益最大（+0.067/+0.035）；均匀重叠数据（blobs_overlap）无增益。

## 局限（诚实声明）
1. **高维均匀数据无增益**：当有监督 RF 已能学好（blobs_overlap），伪标签引入噪声，可能 −0.01；
2. **图分支 O(n²) 内存**：无标注池 >50k 时 kNN 图内存受限（需近似近邻，未实现）；
3. **β 依赖独立验证集**：无 val 时退化为固定 β=0.5；
4. **类别假设**：类先验由小标注集估计，极端类不平衡下预算分配可能偏斜；
5. 深度 SSL 方法（FixMatch/FlexMatch, CVPR）需要 GPU 与增广管线，本系统定位 CPU 轻量级，不与其对标。

## 伦理
- 伪标签会把标注偏差放大进模型；部署前请审查标注质量。
- 不适用于高风险自主决策场景（医疗诊断需人工复核）。
